# GPL-3.0-or-later license

The project is licensed under GPL-3.0-or-later. Auxio, the closest reference app, is GPL-3.0, so this license lets us copy its code instead of only reading it. Media3 and Compose are Apache-2.0, which GPL-3.0 can include, and F-Droid accepts GPL. The cost is that this code can never be folded into a closed-source app. For a personal, offline player that trade is fine.

Code copied or adapted from Auxio keeps its original copyright notice, and the file gets a comment naming the Auxio source file it came from.

## Considered Options

- **Apache-2.0**: rejected. Permissive with a patent grant, but Auxio's code could then only be read, never copied.
- **MIT**: rejected for the same reason, and it has no patent grant.
- **GPL-3.0-only**: rejected. "or later" matches common practice for GPL Android apps and keeps the option of moving to a future GPL version.
